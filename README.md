# Словарь фронтенда

Иллюстрированный словарь JavaScript, React, CSS и браузерных технологий. Учебные карточки объясняют термины через визуальные ассоциации, короткие статьи и примеры кода.

[Открыть сайт](https://frontend-lexicon-x20.wakingbun2.chatgpt.site)

## Возможности

- 21 иллюстрированная карточка с пояснениями и примерами кода.
- Поиск, фильтры по темам и сортировка по алфавиту.
- Избранное с сохранением в localStorage.
- Учебная колода с перелистыванием кнопками, клавиатурой и жестом вниз.
- Анимация перемешивания карточек с паузой и поддержкой reduced motion.
- Адаптивная вёрстка для телефонов, планшетов и компьютеров.

## Технологии

HTML, CSS, JavaScript без фреймворков и сборки. SVG-иконки, CSS transforms, Web Animations API, Pointer Events, native dialog.

## Запуск

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000.

## Структура

- `index.html` — структура страницы и диалоговые окна.
- `style.css` — оформление, анимации и адаптивные правила.
- `app.js` — поиск, фильтры, избранное и учебная колода.
- `terms.js` — данные терминов.
- `assets/` — иллюстрации.
